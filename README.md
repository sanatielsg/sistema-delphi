Aplicação para controle de estoque e vendas. Feita com Delphi estilo RAD raiz.

O que é utilizadno no projeto:
* Delphi versão 12;
* Componente FireDAC;
* Componente Fortes Reports CE;
* Banco de dados Firebird 2.5+.

Atenção:
* Esse projeto está propositalmente com vários problemas que serão resolvidos em evoluções do sistema;
* Basicamente, eu seguirei o estilo clássico de programação Delphi RAD, com os formulários, um Datamodule para conexão com banco de dados, queries e datasources, e um Datamodule para relatórios;
* Já iniciarei com tudo relacionado a banco de dados centralizado no Datamodule, pois acho que isso é o mínimo!;
* Baixa coesão e alto acoplamento (:D);
* Sem testes unitários (tudo no olhômetro e seja o que Deus quiser...);
* Quase nenhum tratamento de erros (para quem gosta de "surpresas").

Serão feitos forks para outras versões que serão evoluções de arquitetura deste projeto.
